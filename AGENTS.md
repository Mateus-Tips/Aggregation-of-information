# AGENTS.md

Contexto para agentes de IA que trabalham neste repo.

## O que é

Agregador de informações (anotações, guias, slides, brag document). Não é um projeto de software: não tem build, testes nem dependências.

Repo compartilhado entre **GitHub da empresa** (conta básica, criada só para isso) e **GitHub pessoal**. A empresa usa **GitLab** para o trabalho real; este repo não faz parte desse fluxo. Ver `README.md`.

## Regras

- Conteúdo em pt-BR, Markdown.
- Nunca adicionar credenciais, tokens ou segredos. Links internos (Jira, GitLab), prints do produto e nomes de projeto são permitidos.
- Novo tema = nova pasta na raiz. Atualizar a tabela de estrutura do `README.md` ao criar pasta.
- Contexto do projeto fica neste arquivo e no `README.md`, não em memória do agente.

## BragDocument

Fluxo e moldes em `BragDocument/empresas/ME/README.md` e `BragDocument/empresas/ME/_templates/`. Seguir o template ao registrar task ou montar consolidado de review.
