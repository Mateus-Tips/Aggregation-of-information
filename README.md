# Aggregation of information

Repositório pessoal de anotações, guias e materiais de estudo.

## Propósito

Ponte de informação entre duas contas GitHub:

- **GitHub da empresa**: conta básica, criada só para este propósito.
- **GitHub pessoal**: conta pessoal.

O trabalho do dia a dia na empresa roda no **GitLab**, não aqui. Este repo existe só para compartilhar conteúdo entre as duas contas GitHub.

## Estrutura

| Pasta | Conteúdo |
|-------|----------|
| `AI-slides/` | Slides e apresentações |
| `BragDocument/` | Brag document (`empresas/`, `pessoal/`) |
| `Git/` | Guias de workflow Git |
| `Tests/` | Anotações de testes (Jest, Vitest) |

## Regras

- Nada de credenciais, tokens ou segredos. Links internos (Jira, GitLab) e prints do produto podem.
- Uma pasta por tema.
